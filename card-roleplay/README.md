# 카드 응대 연습 (card-roleplay)

신용카드 모집인 신입이 손님의 질문·거절에 **3초 안에 입을 열고, 20초 안에 짧고 진실하게** 답하는 반응을 기출문제처럼 반복 훈련하는 모바일 웹앱(PWA)입니다. 목소리가 작은 사람을 위해 **음량과 말 속도 점검**을 중심에 두었습니다.

- 손님(SVG 일러스트)이 질문을 소리 내어 읽고, 읽는 동안 입이 움직입니다.
- ① 반응 타이머(말 시작까지) → ② 답변 타이머(답 끝까지), 반응 시간은 화면에 바로 뜹니다.
- 답변은 녹음·전사(받아쓰기)·평균 음량으로 남고, 결과 화면에서 모범답안 초안과 비교합니다.
- 라이트너 상자(1~3)로 못 푼 문제가 먼저 나옵니다. [오답만 풀기]로 다시 풀기 문항만 연습합니다.
- 백엔드 없음. 모든 데이터는 이 기기 안(localStorage, IndexedDB)에만 저장됩니다.

> **먼저 할 일:** 질문 은행 10문항 중 7문항의 모범답안에 `[확인 필요]`가 있습니다(연회비, 실적 기준, 신용점수 영향, 해지 방법, 사은품 기준, 지점명 등). 실제 연습 전에 **지점 교육 자료로 숫자와 조건을 고치세요.** 앱의 [질문 은행 편집]에서 고치거나 `src/data/seed.json`을 고치면 됩니다.

## 로컬 실행

Node 22.12 이상이 필요합니다.

```bash
cd card-roleplay
npm install
npm run dev        # http://localhost:5173
npm test           # 단위 테스트 (Node 내장 테스트 러너)
npm run build      # dist/ 생성 (서비스 워커 포함)
npm run preview    # 빌드 결과를 로컬에서 확인
```

**휴대폰에서 개발 서버를 볼 때 주의:** 마이크와 서비스 워커는 `https://` 또는 `localhost`에서만 동작합니다. 같은 와이파이의 `http://192.168…:5173`으로 열면 마이크가 막힙니다. 휴대폰 테스트는 다음 중 하나로 하세요.

1. Vercel에 배포한 주소로 열기 (가장 간단)
2. USB 연결 후 PC 크롬 `chrome://inspect` › Port forwarding에서 `5173 → localhost:5173`을 켜고, 휴대폰 크롬에서 `http://localhost:5173` 열기

### 전 과정 자동 점검 (E2E)

```bash
npm i -D playwright && npx playwright install chromium   # 처음 한 번
npm run e2e                                              # 빌드 후 9단계 점검
node e2e/run.mjs --screenshots                           # public/screenshots/*.png 새로 찍기
```

헤드리스 크롬에 가짜 마이크(연속음)·가짜 한국어 음성·가짜 음성 인식을 넣고, `vercel.json`의 운영 헤더(CSP 포함) 아래에서 첫 실행 권한 화면 → 홈 → 오프라인 재실행 → 연습(입 모양, 화면의 반응 시간, 녹음, 결과, 요약) → 기록 재생 → 질문 추가까지 돌리고, 오류와 CSP 위반이 0건인지 확인합니다. **실제 안드로이드 기기, 실제 TTS 음성, 실제 구글 음성 인식, 삼성 인터넷은 이 점검으로 확인되지 않습니다.** 아래 체크리스트로 기기에서 확인하세요.

## 배포 (Vercel)

이 저장소의 루트에는 다른 프로젝트가 있으므로 **Root Directory를 `card-roleplay`로 지정**하는 것이 핵심입니다.

1. [vercel.com](https://vercel.com) › Add New › Project › 이 GitHub 저장소 Import
2. **Root Directory: `card-roleplay`** (Edit을 눌러 지정)
3. Framework Preset은 Vite로 자동 인식됩니다. 빌드 설정은 `vercel.json`에 있습니다(`npm ci` → `npm run build` → `dist`).
4. Deploy → `https://<프로젝트>.vercel.app`

브랜치: 지금 코드는 작업 브랜치에 있습니다. Vercel은 기본적으로 `main`을 운영(Production)으로 배포하고, 다른 브랜치는 Preview 주소로 배포합니다. Preview 주소로 먼저 휴대폰에서 확인한 뒤 `main`에 합치면 됩니다.

CLI로 하려면 `card-roleplay` 폴더에서 `npx vercel`(미리보기), `npx vercel --prod`(운영)를 실행하세요.

`vercel.json`이 거는 헤더: 외부 스크립트를 막는 CSP, 마이크를 이 사이트에만 허용하는 Permissions-Policy, `sw.js`는 캐시하지 않음, `assets/`는 1년 캐시(파일명에 해시가 있음).

## 안드로이드 APK 만들기 (PWABuilder)

이 앱은 PWABuilder가 요구하는 조건(HTTPS, `manifest.webmanifest`의 이름·아이콘 192/512·maskable 아이콘·standalone·스크린샷, 오프라인으로 열리는 서비스 워커)을 갖추고 있습니다.

1. Vercel 주소를 안드로이드 크롬에서 열어 아래 체크리스트를 먼저 통과시킵니다.
2. [pwabuilder.com](https://www.pwabuilder.com)에 Vercel 주소를 넣고 점검합니다.
3. **Package for stores › Android**를 고릅니다. Package ID(예: `app.vercel.<프로젝트>.twa`)와 앱 이름을 확인하고 Generate.
4. 받은 zip에는 설치용 APK, Play 스토어용 AAB, **서명 키(signing.keystore)와 비밀번호**, `assetlinks.json`이 들어 있습니다. **서명 키는 잃어버리면 같은 앱으로 업데이트할 수 없으니 안전한 곳에 보관하세요.**
5. zip 안의 `assetlinks.json`을 `card-roleplay/public/.well-known/assetlinks.json`으로 넣고 다시 배포합니다. 이 파일이 있어야 앱 위쪽에 브라우저 주소창이 뜨지 않습니다. (빌드에 그대로 복사되며 서비스 워커 캐시에서는 빠지도록 해 두었습니다.)
6. APK를 휴대폰에 옮겨 설치합니다(“출처를 알 수 없는 앱 설치” 허용 필요). 설치한 앱에서 체크리스트를 다시 확인하세요.

APK(TWA)는 내부적으로 휴대폰의 크롬으로 실행되므로 마이크 권한, 음성 읽기, 전사는 크롬과 같게 동작할 것으로 예상합니다. 다만 기기에서 직접 확인하지는 못했습니다.

## 결정 사항

명세에서 정하지 않았거나 모호했던 부분은 다음처럼 정했습니다.

**구성**

1. **위치:** 저장소 루트에 다른 프로젝트가 있어 `card-roleplay/` 폴더의 독립 앱으로 만들었습니다. Vercel에서 Root Directory만 지정하면 됩니다.
2. **바닐라 JS + Vite**(React 없음). 의존성은 Vite 하나, 앱 번들은 gzip 약 21KB입니다.
3. **해시 라우팅**(`#/practice`). 정적 호스팅·오프라인·APK 어디서 새로고침해도 404가 나지 않습니다.
4. **서비스 워커는 플러그인 없이** `vite.config.js`가 빌드 파일 목록으로 생성합니다. 페이지는 캐시 우선이라 오프라인에서도 바로 열리고, 새 배포는 다음 실행 때 반영됩니다.
5. **연습 시작 전 [응대 시작] 버튼 한 번**: 브라우저는 사용자의 탭 없이 음성 재생·오디오 처리를 시작하지 못하게 막기 때문입니다. 이때 마이크를 한 번 열고 세션 끝까지 유지합니다(문항마다 권한을 묻지 않도록).

**측정**

6. **반응 시간** = 손님 음성이 끝난 순간 → 말 시작. **말 시작**은 ① 첫 음성 인식 결과 ② 음량이 "말 시작 감지" 선을 0.15초 이상 넘긴 시점(넘기 시작한 순간) 중 **빠른 쪽**입니다. 음성 인식 결과는 실제 발화보다 0.5~1초 늦게 오는 경우가 많아 대개 음량이 더 정확합니다.
7. **반응 제한(3초)을 넘기면** 원형 타이머가 답변 단계로 넘어가고 "초과"를 표시합니다. 그 뒤에라도 말을 시작하면 실제 반응 시간(예: 4.2초)을 기록합니다.
8. **답변 타이머(20초)** 는 말 시작 순간부터(반응 초과 시에는 초과 순간부터) 잽니다. 시간이 끝나면 자동으로 답변을 끝냅니다.
9. **녹음 범위**는 손님 질문이 끝난 순간부터 답변 끝까지입니다. 망설인 시간도 들어야 고칠 수 있기 때문입니다.
10. **음량**은 0~100 눈금(−60 dBFS = 0, 0 dBFS = 100)입니다. **평균 음량**은 말 시작 이후 측정값 중 **큰 절반의 평균**입니다(단어 사이 쉼이 평균을 끌어내리지 않도록). 마이크의 **자동 음량 보정(AGC)은 껐습니다.** 켜 두면 작은 목소리를 키워서 "충분히 크다"고 잘못 보여 주기 때문입니다.
11. 기본 기준선(너무 작음 45, 말 시작 30)은 추정값입니다. 기기·거리마다 달라서 **설정 › 목소리 크기 점검**에서 ① 조용할 때 소음 기준 ② 손님이 1m 떨어져 들을 크기로 말한 목소리 기준을 잡도록 했습니다.

**출제와 기록**

12. **라이트너:** 새 질문은 상자 1. 문항을 넘길 때 "다시 풀기"가 꺼져 있으면 잘 답한 것으로 보고 상자 +1(최대 3), 켜져 있으면 상자 1로 보냅니다. **반응 초과, 말 시작 감지 안 됨, 답변 제한 시간 초과 중 하나면 [다시 풀기에 넣기]가 미리 켜져** 있고, 직접 끌 수 있습니다.
13. **[건너뛰기]** 는 못 푼 문제로 보고 다시 풀기에 넣습니다.
14. **출제 순서:** 상자 번호가 낮은 순 → 오래전에 본 순으로 고른 뒤, 고른 문항의 순서는 섞습니다.
15. **[오답만 풀기]** 는 다시 풀기 표시된 문항을 **전부** 냅니다(세션 문항 수 제한 없음).
16. **[다시 듣기]** 는 그 문항을 처음부터 다시 합니다(그때까지의 녹음·전사는 버림). 횟수는 결과에 남습니다.
17. 결과는 **[다음 문제]를 누르거나 화면을 떠날 때** 저장됩니다. 그래서 결과 화면에서 고친 자기평가·다시 풀기 표시가 반영됩니다.
18. 자기평가 체크 3개(들리는 크기 / 말 속도 / 첫 문장 또렷함)는 "잘 됐으면 체크"입니다. 상자 이동에는 쓰지 않고 기록으로만 남깁니다.
19. **질문 은행 가져오기**는 "합치기(같은 id는 파일 내용으로 덮어씀)"와 "전부 바꾸기" 중 고릅니다.

**음성과 폴백**

20. **손님별로 음 높이만** 다르게 했습니다(기기의 한국어 음성은 보통 1~2개뿐이라). 말 속도는 설정값(0.9~1.1)을 모든 손님에 적용합니다.
21. **음성 읽기가 안 되거나 한국어 음성이 없으면** 문장 길이로 읽는 시간을 추정해 자막과 입 모양만 움직이고, 한국어 음성 설치 방법을 안내합니다.
22. **전사가 안 되는 브라우저(삼성 인터넷 등)** 에서는 녹음·음량만 동작하고 "크롬에서 열면 전사가 됩니다"를 홈·연습·결과·설정에 안내합니다. 전사가 실행 중 막히면(`not-allowed`, `network`, `audio-capture` 등) 그 세션은 전사 없이 계속합니다.

## 2단계: AI 꼬리 질문 (구조만 열어 둠)

지금은 구현하지 않았고, 꺼진 상태로 자리만 있습니다.

| 파일 | 역할 |
|---|---|
| `src/providers/question-provider.js` | 연습 화면은 `nextSession({ mode, size })` 인터페이스만 압니다. 지금은 정적 공급자(로컬 질문 은행 + 라이트너). AI 공급자도 같은 인터페이스로 바꿔 끼우면 됩니다. |
| `src/providers/followup-provider.js` | `followup({ question, transcript, personaId }) → 꼬리 질문 1개 또는 null`. 플래그가 꺼져 있으면 아무것도 하지 않습니다. UI에는 아직 연결하지 않았습니다. 연결 지점: `practice.js`의 결과 화면. |
| `src/config/features.js` | 클라이언트 플래그 `VITE_FEATURE_AI_FOLLOWUP=on` |
| `api/followup.js` | Vercel 서버리스 함수 `POST /api/followup`. 서버 플래그 `FEATURE_AI_FOLLOWUP=on`이 아니면 404, 켜도 지금은 501. |

2단계 구현 때 지킬 것: Anthropic API 키는 Vercel 환경변수 `ANTHROPIC_API_KEY`에만 두고 `VITE_` 접두어를 붙이지 않습니다(붙이면 클라이언트 번들에 들어감). 입력 길이 제한과 호출 횟수 제한을 먼저 넣고, 모델은 구현 시점의 최신 목록을 확인해 고릅니다.

## 안드로이드 크롬 확인 체크리스트

Vercel 주소(https)를 **안드로이드 크롬**에서 열고 확인하세요. APK로 만든 뒤에도 같은 항목을 한 번 더 봅니다.

- [ ] **마이크 권한**: 첫 실행에 "마이크를 써도 될까요?" 화면 → [마이크 허용하기] → 크롬 권한 창에서 허용 → 홈으로 이동
- [ ] **한국어 음성 존재**: 설정 › 이 기기 지원 현황에 "한국어 음성 1개 이상", [미리 듣기]에서 한국어로 들림. 없으면 안드로이드 설정 › 텍스트 음성 변환 › Google 음성 엔진 › 한국어 데이터 설치
- [ ] **립싱크**: 연습에서 손님이 질문을 읽는 동안 입이 움직이고, 끝나면 닫힘
- [ ] **전사 동작**: 답할 때 화면 아래 회색 칸에 말이 실시간으로 적힘
- [ ] **반응 시간**: 말을 시작하자마자 "반응 n.n초"가 초록(3초 이내) 또는 빨강(초과)으로 뜸
- [ ] **녹음 재생**: 결과 화면 [내 녹음]에서 내 목소리가 재생되고 길이가 표시됨. 기록 화면 [▶ 녹음 듣기]도 재생됨
- [ ] **전사 + 녹음 동시**: 같은 문항에서 전사 글자와 녹음 소리가 **둘 다** 남는지. 녹음이 무음이면 설정에서 전사를 끄고 다시 확인
- [ ] **음량 바**: 설정 › 마이크 테스트에서 말할 때 바가 움직이고, ①②로 기준선을 맞출 수 있음
- [ ] **오프라인 홈 화면 열림**: 한 번 연 뒤 비행기 모드 → 크롬(또는 설치한 앱)에서 다시 열기 → 홈이 열림
- [ ] **설치**: 홈 [홈 화면에 앱 설치] 또는 크롬 메뉴 › 앱 설치 → 아이콘으로 열면 주소창 없이 열림
- [ ] (선택) **삼성 인터넷**에서 열면 "크롬에서 열면 전사가 됩니다" 안내가 뜨고, 녹음·음량은 동작
