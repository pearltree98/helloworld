# 현장노트

카드 모집인의 방문 영업 기록과 성적표. 방문할 때마다 20초 안에 기록하고, 쌓인 기록을 시험 성적표처럼 영역별 점수로 봅니다.

- **기록**: 방문 시작을 누르면 위치·시간·날씨가 자동으로 들어갑니다. 업종, 만난 사람의 역할, 첫 반응, 도달 단계, 거절 사유와 내 대처, 결과를 칩으로 고릅니다.
- **성적표**: 영업 단계별 통과율, 거절 사유별 극복률, 대처 기법별 성공률, 업종·시간대·요일·날씨 등 환경별 신청률. 강점·약점 Top 3는 같은 묶음 평균과 비교하고, 5건 미만은 판단을 보류합니다(Wilson 신뢰구간).
- **지도**: 방문한 장소를 결과 색으로 표시하고, 장소마다 방문 이력(반응·대처·결과)을 타임라인으로 봅니다.
- **설정**: 선택 항목 추가·숨김, JSON 백업·복원, 엑셀(CSV) 내보내기, 데모 데이터.

## 개인정보

이 앱은 고객이 아니라 나의 영업 행동과 결과를 기록합니다.

- 고객 이름, 전화번호, 이메일, 주민·외국인등록번호, 카드·계좌번호, 집 주소, 생년월일, 나이·성별, 사진은 입력란이 없습니다.
- 메모·장소 별칭·상품명은 저장 전에 `js/privacy.js`가 검사해, 개인정보로 보이는 표현이 있으면 저장을 막습니다. 백업 파일을 불러올 때도 같은 검사로 가립니다.
- 모든 데이터는 기기의 브라우저 저장소(IndexedDB)에만 있습니다. 서버가 없습니다.
- 외부로 나가는 값은 주소·날씨 조회용 좌표(내 위치)뿐이며, 설정에서 끌 수 있습니다.

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
cd fieldnote && python3 -m http.server 8080   # http://localhost:8080
npm test                                      # 저장소 루트에서: 통계·개인정보 검사 단위 테스트 포함
```

위치 기능은 https 또는 localhost에서만 동작합니다. 배포는 이 폴더를 정적 호스팅(Vercel 등)에 올리면 됩니다.
