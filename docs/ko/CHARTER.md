# Stepback 공익 헌장 (한국어)

Stepback은 일상의 위험으로 다치는 사람이 줄어들도록 존재합니다. 공공재입니다. 무료로 쓰고, 자유롭게 복제하며, 누구도 이것을 사업으로 바꿀 수 없도록 만들었습니다. 이 문서는 그것이 실제로 무엇을 뜻하는지, 어떤 사례에서 가져왔는지, 어떻게 운영되는지를 적습니다.

## 1. 약속

1. **누구에게나 영원히 무료.** 유료 등급, 프리미엄 기능, 유료 장벽이 없습니다.
2. **광고 없음.** 사이트의 어떤 것도 팔지 않고, 어떤 자리도 팔지 않습니다.
3. **추적 없음.** 분석 스크립트, 제3자 쿠키, 프로파일링이 없습니다. 유일한 식별자는 "한 사람당 교훈 한 번"을 세기 위해 브라우저가 스스로 보관하는 무작위 id뿐입니다.
4. **제품 안에 돈 없음.** 결제, 약정, 후원금, 기금이 없습니다. 티켓은 교훈과 한마디일 뿐, 어떤 것의 쿠폰도 아닙니다.
5. **열린 콘텐츠.** 모든 사례와 티켓은 크리에이티브 커먼즈 저작자표시-동일조건변경허락 4.0(CC BY-SA 4.0)으로 공개됩니다. 출처를 밝히고 같은 조건으로 나눈다면 누구나 복제·번역·인쇄·재가공할 수 있습니다.
6. **열린 데이터.** 전체 공개 데이터를 누구나 `/api/export`에서 내려받을 수 있으며, 방문자 id는 들어 있지 않습니다.
7. **열린 코드.** 소프트웨어는 GNU Affero 일반 공중 사용 허가서 v3(AGPL-3.0)입니다. 누구나 자기 복사본을 운영할 수 있고, 수정한 복사본을 서비스로 운영하는 사람은 변경 내용을 공개해야 합니다.
8. **탓하지 않음.** 사례는 사람이 아니라 구조를 기록합니다. 작성 폼에 가해자·피해자 칸이 없고, 사이트의 어떤 것도 누군가를 망신 주기 위한 것이 아닙니다.
9. **투명한 비용.** 호스팅과 도메인 비용을 공개합니다. 비용을 위해 기부를 받게 된다면 장부를 공개하고, 기부는 어떤 영향력도 사지 못합니다.
10. **포크 가능한 설계.** 운영자가 이 헌장에서 벗어나더라도 5~7항 덕분에 누구나 코드와 데이터를 가져가 이어갈 수 있습니다.

## 2. 어디서 가져왔나

수십 년 동안 쓸모와 신뢰를 지킨 플랫폼들은 몇 가지 설계를 공유합니다. Stepback은 그것을 의도적으로 따릅니다.

| 사례 | 하는 일 | Stepback이 가져온 것 |
|---|---|---|
| **위키백과 / 위키미디어 재단** | 다수의 소액 개인 기부로 운영. 독립성을 위해 광고 거부. 모든 글은 CC BY-SA. | 광고 없음, CC BY-SA 콘텐츠, "돈을 대는 쪽이 내용을 좌우할 수 없어야 한다"는 원칙. |
| **OpenStreetMap** | 직원 1명의 자원봉사 재단. 데이터는 동일조건변경허락(ODbL)으로 공개되어 기업을 포함해 누구나 쓰되 개선은 되돌려야 함. | 데이터 내보내기, 동일조건 라이선스, 최소한의 조직. |
| **iNaturalist** | 2023년 독립 비영리로 전환. 플랫폼과 데이터는 계속 무료. 감사 재무제표와 세무 신고를 공개. | 비용 장부 공개. 법인이 필요해진다면 비영리만 허용. |
| **NASA 항공안전보고시스템(ASRS)** | 조종사가 처벌 권한이 있는 규제기관이 아닌 NASA에 아차 사고를 보고. 보고는 비밀이며 규제기관은 제한적 면책을 줌. 이 분리가 정직한 보고를 가능하게 함. | 탓하지 않음, 신원 불필요, "무슨 일이 있었나를 기록하는 것"과 "누구 잘못인지 판단하는 것" 사이의 엄격한 벽. |
| **서스펜디드 커피 / 벽에 붙은 식권** | 손님이 미리 내고 낯선 사람이 받아 감. 작고, 보이고, 1회성인 선물. | 티켓 벽. 단, 완전히 비금전적으로: 선물은 교훈과 한마디. |

## 3. 왜 돈을 아예 뺐나

이전 설계에는 선택 사항인 "안전 기금 약정"이 있었습니다. 의도적으로 제거했습니다.

- **신뢰.** 돈을 만지는 무료 서비스에 사람들이 가장 먼저 묻는 것은 "그 돈은 누가 갖나"입니다. 돈을 빼면 질문이 사라집니다.
- **운영 비용.** 기금에는 법인, 회계, 감사, 집행 규칙이 필요합니다. 그 어느 것도 후진하는 차로부터 사람을 지켜 주지 않습니다.
- **동기 밀어내기.** 친사회적 행동에 가격을 붙이면 오히려 그 행동이 줄어든다는 것은 경제학에서 잘 알려진 효과입니다. "이 교훈이 나를 지켰다"는 한마디는 값이 붙지 않을 때 더 큽니다.
- **위의 사례들.** 위키백과, OpenStreetMap, ASRS 모두 제품 안에는 돈이 없고, 비용은 조직 차원에서 공개적으로 다룹니다.

호스팅에 자금이 필요해진다면 모델은 위키미디어 방식입니다. 다수의 소액 기부, 공개된 회계, 영향력을 가질 만큼 큰 단일 기부자 없음.

## 4. 공공재의 경제학

교훈은 **비경합적**이고(내가 읽어도 닳지 않음) 일단 공개되면 **비배제적**입니다(누구도 막을 수 없음). 이런 재화는 시장이 과소 공급하기 때문에 비시장 구조가 필요합니다. Stepback은 시장이 주지 않을 세 가지를 공급합니다.

- **공통 형식**(원천 → 상태 → 피하는 행동). 한 사람의 아찔한 순간이 낯선 사람에게 쓸모 있어지도록.
- **호혜 장치**(1회성 티켓). 돈을 주지 않고도 독자를 기여자로 바꾸도록.
- **사회적 증거**(교훈 수). 안전한 선택이 보통으로 보이도록.

결과는 포지티브섬입니다. 기록한 사람은 인정을, 읽는 사람은 보호를, 다음 사람은 한마디를 얻고, 아무도 돈을 내지 않습니다.

## 5. 운영: 오스트롬의 원칙에 따라

엘리너 오스트롬은 오래 지속된 공유지 연구에서 여덟 가지 설계 원칙을 제시했습니다. Stepback은 다음과 같이 대응하며, *나중*이라고 표시한 것은 아직 만들지 않았습니다.

| 오스트롬 원칙 | Stepback |
|---|---|
| 명확한 경계 | 자원은 사례와 티켓의 집합. 누구나 읽고, 탓하지 않는다는 규칙 안에서 누구나 기여. |
| 지역 조건에 맞는 규칙 | 언어 공동체마다 자기 사례와 번역을 가짐. 같은 구조, 지역의 내용. |
| 집단적 선택 | 규칙은 이 헌장과 공개 저장소에 있고, 변경은 공개적으로 제안·논의. *나중: 헌장 변경 절차 공개.* |
| 사용자에 의한 감시 | 모든 콘텐츠가 공개되고 내려받을 수 있어 누구나 감사 가능. *나중: 신고 버튼과 공개 중재 기록.* |
| 단계적 제재 | *나중:* 숨김 → 제한 → 차단. 각 단계와 사유를 공개 기록. |
| 저렴한 분쟁 해결 | *나중:* 사례에 대한 이의를 다루는 공개 이슈 트래커. |
| 자치의 권리 | AGPL과 CC BY-SA가 보장. 어떤 집단이든 포크해서 직접 운영 가능. |
| 중첩된 조직 | 하나의 코드베이스와 데이터 안의 언어 공동체들. |

## 6. 사회학, 짧게

- **아차 사고 보고는 처벌이 없을 때만 작동한다**(ASRS). 그래서 탓하지 않고 신원을 묻지 않는다.
- **하인리히 법칙(1 : 29 : 300)**: 큰 사고는 많은 아차 사고 위에 있다. 작은 것을 모으는 것이 핵심이다.
- **사회적 증거**는 경고보다 행동을 더 움직인다. 숫자는 보여 주고 공포는 보여 주지 않는다.
- **호혜**는 무한히 복사되는 '좋아요'가 아니라 희소하고 개인적인 선물이 일으킨다. 그래서 1회성 티켓이다.
- **공유지 기반 동료 생산**(벤클러): 기여 단위가 작고, 형식이 명확하며, 결과가 쓰이는 것이 보일 때 사람들은 공공재에 기여한다. 그래서 세 칸과 공개된 숫자다.

## 7. 이 헌장이 약속하지 않는 것

사이트가 영원히 존재한다고 약속하지 않습니다. 멈추더라도 아무것도 잃지 않는다고 약속합니다. 코드와 데이터는 이미 모두의 손에 있습니다.
