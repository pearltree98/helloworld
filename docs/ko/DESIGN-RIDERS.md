# 설계: 배달 라이더용 Stepback

2026-11-05. 다섯 외부 평가(`docs/EVALUATION.md`)를 반영한 설계. 코드는 아직 없다.

## 1. 한 문장

배달 라이더가 "어디서, 뭐가 위험했고, 다음엔 이렇게 피한다"를 세 줄과 블랙박스 영상으로 남기고, 같은 구역을 도는 라이더가 그걸 미리 보는 사이트. 확인된 제보에는 소액을 지급한다. 사고 영상은 받지 않는다.

## 2. 누구를 위한 것인가

- 쓰는 사람: 배달 라이더. 매일 같은 위험에 노출되고, 사고가 나면 그날부터 수입이 끊긴다. 쓸 이유가 있다.
- 읽는 사람: 같은 구역(동 단위)의 라이더. 내가 내일 지나갈 자리의 위험을 미리 안다.
- 아닌 사람: 일반 대중. 나중 일이다.

## 3. 핵심 순환

1. 콜을 기다리는 동안 세 줄을 쓴다. 30초, 한 손.
2. 내 구역의 기록을 본다.
3. 도움이 됐으면 "덕분에"를 누른다. 쓴 사람에게 간다.
4. 일주일 뒤 "해 봤나요?"에 답한다. 이것이 행동 측정이다.

## 4. 기록 한 건의 모양

| 칸 | 필수 | 내용 |
|---|---|---|
| 어디서 | ✓ | 동 + 장소. 예) 성수동 ○○아파트 지하주차장 경사로 |
| 뭐가 위험했나 | ✓ | 한 줄 |
| 다음엔 이렇게 피한다 | ✓ | 한 줄. "~할 때 ~한다" 꼴을 권한다 |
| 유형 | ✓ (고르기) | 교차로 / 정차 차량 / 골목 합류 / 주차장·경사로 / 날씨·노면 / 보행자 / 화물차 / 시간 압박 / 기타 |
| 영상 | 권장 | 블랙박스·액션캠 15초 이내. **피한 영상만.** 사고가 난 영상은 받지 않는다. 번호판·얼굴은 가린 뒤에만 공개 |
| 사진 | | 영상이 없을 때 한 장 |
| 상태 | 자동 | 확인 전 / 확인됨 / 숨김 |

없는 칸: 가해자, 피해자, 업체, 번호판, 위험 점수.

## 5. 화면 다섯 개

0. **오늘의 아찔**: 전국에서 오늘 확인된 제보가 올라오는 피드. 영상이 먼저 보인다. 해석은 붙이지 않고, 세 줄과 "나는 이렇게 한다"만 있다.
1. **내 구역**: 내가 배달하는 동네를 고르면 그곳의 기록. 장소별·유형별로 본다. 처음 온 사람은 여기서 시작한다.
2. **쓰기**: 칸 세 개와 유형 하나. 폼과 같은 말을 쓴다.
3. **기록 하나**: 세 줄, 장소, 확인 상태, 다른 라이더가 덧붙인 "나는 이렇게 한다", 덕분에 수, 신고 버튼.
4. **내 것**: 내가 쓴 것, 내가 덕분에 누른 것, "해 봤나요?" 답할 것.

## 6. 규칙 다섯 개

평가에서 나온 문제 하나하나에 대응한다.

| 규칙 | 막는 문제 |
|---|---|
| **로그인 필수, 표시는 익명.** 카카오 로그인, 한 사람 한 계정, 화면에는 별명만. 항공 보고제도처럼 익명이 아니라 비밀. | 위조 식별자, 스팸, 숫자 조작, 사칭 |
| **사람은 안 적고 장소는 적는다.** 번호판·전화번호·업체명 꼴은 입력에서 막는다. | 명예훼손, 피해자 특정 |
| **확인 전 / 확인됨.** 바로 올라가되 표시. 경력 라이더 검토자가 보고 맞으면 확인됨. 틀린 조언은 확인됨을 못 받는다. | 틀린 안전 조언 |
| **신고하면 숨기고, 요청하면 지운다.** 신고 즉시 숨김, 24시간 안에 판단. 삭제 요청은 지체 없이. 사용자 글에 자유 라이선스를 걸지 않는다. | 삭제 의무와 라이선스의 충돌 |
| **함께 고친다.** "다음엔 이렇게 피한다"에 다른 라이더가 "나는 이렇게 한다"를 덧붙이고, 덕분에를 많이 받은 것이 위로 간다. | 자정 작용 없음, 운영자 혼자 관리 |

## 7. 쓰는 사람의 이익

- **확인된 제보에 소액 지급.** 금액은 재원이 정해진 뒤 정한다. 조건: 피한 영상 + 세 줄 + 검토자 확인 + 중복 아님. 월 상한을 둔다.
- 내 구역 위험을 미리 안다.
- "덕분에"가 온다. 내 글이 누군가를 지켰다는 신호.
- 주간 "내 구역 아찔 3건" 카드. 단톡방에 그대로 올릴 수 있다.

티켓은 없다.

## 7-1. 영상의 규칙

| 규칙 | 이유 |
|---|---|
| 사고 영상은 받지 않는다. 피한 영상만 | 사고를 바라게 만들지 않는다. 다친 사람이 찍힌 영상의 법적 위험을 피한다 |
| 15초 이내, 아찔한 순간 앞뒤만 | 보는 데 오래 걸리면 안 본다. 저장 비용도 준다 |
| 번호판·얼굴은 가린 뒤에만 공개. 1단계는 검토자가 눈으로 확인, 2단계는 자동 가림 | 초상권, 개인정보 |
| 제보자는 촬영자 본인이어야 하고, 공개에 동의하며, 언제든 삭제를 요청할 수 있다 | 권리, 삭제 의무 |
| 1단계에서는 영상을 직접 저장하지 않는다. 제보자가 유튜브 '일부 공개'로 올리고 링크를 내거나, 운영 채널에 올린다 | 서버·트래픽 비용 0. 유튜브 플레이어를 그대로 쓴다 |
| 확인 전 영상은 공개하지 않는다 | 가리지 않은 영상이 한 번이라도 나가면 끝이다 |

## 7-2. 돈은 어디서 오는가

광고가 아니다. 광고는 조회가 수만 건일 때만 돈이 되고, 그 조회는 지금 한문철TV에 있다.

| 돈을 낼 이유가 있는 쪽 | 왜 내는가 | 무엇을 사는가 |
|---|---|---|
| 배달 플랫폼·배달대행사 | 라이더 안전 의무가 법에 있다. 사고는 보험료·이탈·평판 비용이다 | 구역별·지점별 아차 사고 데이터, 교육용 영상 |
| 이륜차 보험사 | 이륜차 손해율이 높다. 사고가 줄면 바로 이익 | 위험 지점 데이터, 가입자 교육 |
| 공공기관(도로교통공단, 안전보건공단, 지자체) | 이륜차 사고 감소가 과제다 | 데이터, 캠페인 소재 |

순서: 확인된 제보 100건이 쌓이기 전에는 제안할 수 없다. 그래서 1단계는 지급 없이, 또는 운영자가 정한 아주 작은 시범 금액으로 시작한다. **재원이 없을 때 공개적으로 금액을 약속하지 않는다.** 약속하면 지켜야 한다.

## 8. 측정

| 재는 것 | 뜻 |
|---|---|
| 주간 새 기록 수, 서로 다른 작성자 수 | 쓰는가 |
| 구역당 기록 수 | 밀도가 생기는가 |
| 덕분에 수 | 읽고 도움이 됐는가 |
| "해 봤나요?" 예 비율 | 행동으로 갔는가 |
| 신고 비율, 숨김까지 걸린 시간 | 안전한가 |
| 영상 있는 제보 비율, 확인됨 비율 | 지급 대상이 되는 품질인가 |

## 9. 뺀 것

티켓 벽, 15개 언어(한국어만), 헌장 페이지(원칙은 한 문단으로), 작성자가 고르는 5×5 위험 점수, 사용자 글의 CC 라이선스, 전체 내보내기(확인됨 글만, 삭제 요청 시 제외), 광고, 사고 영상.

## 10. 지키는 것

보는 사람에게 무료, 광고 없음, 추적 없음, 탓하지 않음, 코드 공개. 돈은 데이터를 사는 기관에서 와서 제보한 라이더에게 간다.
"아무 일도 일어나지 않은 것이 가장 큰 승리" — 단, 화면에서는 "아차 사고는 경고다"와 짝을 짓는다.

## 11. 단계

| 단계 | 내용 | 기간 |
|---|---|---|
| 1 | 쓰기(세 줄 + 유튜브 링크), 오늘의 아찔, 내 구역 읽기, 카카오 로그인, 신고·숨김·삭제, 검토자 확인 표시, 번호판·전화번호 차단 | 3주 |
| 2 | 덕분에, 해 봤나요, 나는 이렇게 한다, 주간 카드, 지급 장부(누가 언제 얼마) | 2주 |
| 3 | 자동 번호판·얼굴 가림, 직접 영상 저장, 지도, 위치 기반 알림 | 이후 |
| 병행 | 확인된 제보 100건이 되면 플랫폼·보험사에 데이터 제안 | |

## 12. 기술

- 지금 코드에서 가져오는 것: Express + SQLite 구조, 빌드 없는 프론트, 테스트 방식, 카드 생성기.
- 바꾸는 것: 식별(카카오 로그인 + 세션), 사례 테이블(세 줄 + 장소 + 유형 + 상태), 검토·신고·삭제 테이블, 속도 제한, 일반 주소 라우팅(해시 라우터 제거, 검색·미리보기 가능).
- 휴대폰 우선. 한 손으로, 콜 사이에.

## 13. 열린 질문

- 검토자를 처음 누가 맡는가. 경력 라이더 2~3명이 필요하다.
- 구역은 행정동으로 할지, 라이더가 직접 그리는 범위로 할지.
- 1단계 시범 지급을 할지, 한다면 운영자 자비로 얼마까지 할지.
- 유튜브 링크 방식에서 제보자가 영상을 지우면 기록에서 어떻게 처리할지.
