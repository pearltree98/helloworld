# 설계: 배달 라이더용 Stepback

2026-11-05. 다섯 외부 평가(`docs/EVALUATION.md`)를 반영한 설계. 코드는 아직 없다.

## 1. 한 문장

배달 라이더가 "어디서, 뭐가 위험했고, 다음엔 이렇게 피한다"를 세 줄로 남기고, 같은 구역을 도는 라이더가 그걸 미리 보는 사이트.

## 2. 누구를 위한 것인가

- 쓰는 사람: 배달 라이더. 매일 같은 위험에 노출되고, 사고가 나면 그날부터 수입이 끊긴다. 쓸 이유가 있다.
- 읽는 사람: 같은 구역(동 단위)의 라이더. 내가 내일 지나갈 자리의 위험을 미리 안다.
- 아닌 사람: 일반 대중. 나중 일이다.

## 3. 핵심 순환

1. 콜을 기다리는 동안 세 줄을 쓴다. 30초, 한 손.
2. 내 구역의 기록을 본다.
3. 도움이 됐으면 "덕분에"를 누른다. 쓴 사람에게 간다.
4. 일주일 뒤 "해 봤나요?"에 답한다. 이것이 행동 측정이다.

## 4. 기록 한 건의 모양

| 칸 | 필수 | 내용 |
|---|---|---|
| 어디서 | ✓ | 동 + 장소. 예) 성수동 ○○아파트 지하주차장 경사로 |
| 뭐가 위험했나 | ✓ | 한 줄 |
| 다음엔 이렇게 피한다 | ✓ | 한 줄. "~할 때 ~한다" 꼴을 권한다 |
| 유형 | ✓ (고르기) | 교차로 / 정차 차량 / 골목 합류 / 주차장·경사로 / 날씨·노면 / 보행자 / 화물차 / 시간 압박 / 기타 |
| 사진 | | 한 장. 사람·번호판이 찍히면 올라가지 않는다 |
| 상태 | 자동 | 확인 전 / 확인됨 / 숨김 |

없는 칸: 가해자, 피해자, 업체, 번호판, 위험 점수.

## 5. 화면 네 개

1. **내 구역**: 내가 배달하는 동네를 고르면 그곳의 기록. 장소별·유형별로 본다. 처음 온 사람은 여기서 시작한다.
2. **쓰기**: 칸 세 개와 유형 하나. 폼과 같은 말을 쓴다.
3. **기록 하나**: 세 줄, 장소, 확인 상태, 다른 라이더가 덧붙인 "나는 이렇게 한다", 덕분에 수, 신고 버튼.
4. **내 것**: 내가 쓴 것, 내가 덕분에 누른 것, "해 봤나요?" 답할 것.

## 6. 규칙 다섯 개

평가에서 나온 문제 하나하나에 대응한다.

| 규칙 | 막는 문제 |
|---|---|
| **로그인 필수, 표시는 익명.** 카카오 로그인, 한 사람 한 계정, 화면에는 별명만. 항공 보고제도처럼 익명이 아니라 비밀. | 위조 식별자, 스팸, 숫자 조작, 사칭 |
| **사람은 안 적고 장소는 적는다.** 번호판·전화번호·업체명 꼴은 입력에서 막는다. | 명예훼손, 피해자 특정 |
| **확인 전 / 확인됨.** 바로 올라가되 표시. 경력 라이더 검토자가 보고 맞으면 확인됨. 틀린 조언은 확인됨을 못 받는다. | 틀린 안전 조언 |
| **신고하면 숨기고, 요청하면 지운다.** 신고 즉시 숨김, 24시간 안에 판단. 삭제 요청은 지체 없이. 사용자 글에 자유 라이선스를 걸지 않는다. | 삭제 의무와 라이선스의 충돌 |
| **함께 고친다.** "다음엔 이렇게 피한다"에 다른 라이더가 "나는 이렇게 한다"를 덧붙이고, 덕분에를 많이 받은 것이 위로 간다. | 자정 작용 없음, 운영자 혼자 관리 |

## 7. 쓰는 사람의 이익

- 내 구역 위험을 미리 안다. 이것이 첫째다.
- "덕분에"가 온다. 내 글이 누군가를 지켰다는 신호.
- 주간 "내 구역 아찔 3건" 카드. 단톡방에 그대로 올릴 수 있다.

티켓은 없다.

## 8. 측정

| 재는 것 | 뜻 |
|---|---|
| 주간 새 기록 수, 서로 다른 작성자 수 | 쓰는가 |
| 구역당 기록 수 | 밀도가 생기는가 |
| 덕분에 수 | 읽고 도움이 됐는가 |
| "해 봤나요?" 예 비율 | 행동으로 갔는가 |
| 신고 비율, 숨김까지 걸린 시간 | 안전한가 |

## 9. 뺀 것

티켓 벽, 15개 언어(한국어만), 헌장 페이지(원칙은 한 문단으로), 작성자가 고르는 5×5 위험 점수, 사용자 글의 CC 라이선스, 전체 내보내기(확인됨 글만, 삭제 요청 시 제외).

## 10. 지키는 것

무료, 광고 없음, 추적 없음, 탓하지 않음, 코드 공개.
"아무 일도 일어나지 않은 것이 가장 큰 승리" — 단, 화면에서는 "아차 사고는 경고다"와 짝을 짓는다.

## 11. 단계

| 단계 | 내용 | 기간 |
|---|---|---|
| 1 | 쓰기, 내 구역 읽기, 카카오 로그인, 신고·숨김·삭제, 확인 표시, 번호판·전화번호 차단 | 2~3주 |
| 2 | 덕분에, 해 봤나요, 나는 이렇게 한다, 주간 카드 | 2주 |
| 3 | 지도, 위치 기반 알림(위험 직전 개입) | 이후 |

## 12. 기술

- 지금 코드에서 가져오는 것: Express + SQLite 구조, 빌드 없는 프론트, 테스트 방식, 카드 생성기.
- 바꾸는 것: 식별(카카오 로그인 + 세션), 사례 테이블(세 줄 + 장소 + 유형 + 상태), 검토·신고·삭제 테이블, 속도 제한, 일반 주소 라우팅(해시 라우터 제거, 검색·미리보기 가능).
- 휴대폰 우선. 한 손으로, 콜 사이에.

## 13. 열린 질문

- 검토자를 처음 누가 맡는가. 경력 라이더 2~3명이 필요하다.
- 구역은 행정동으로 할지, 라이더가 직접 그리는 범위로 할지.
- 사진의 번호판·얼굴을 자동으로 가릴지, 아예 받지 않을지.
